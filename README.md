# My Portfolio Pal

Create a modern, responsive Stock Portfolio Tracker web app using React, JavaScript, and Tailwind CSS.

Core Features

Dashboard with Total Investment, Total Stocks, Total Shares

Add stocks with symbol + quantity

Use hardcoded demo prices:
AAPL: $180, TSLA: $250, GOOGL: $140, MSFT: $420, AMZN: $185, META: $500, NFLX: $650, NVDA: $120

Automatically calculate: Price × Quantity

Portfolio table with Edit & Delete

Combine duplicate stocks automatically

Search and filter stocks

Portfolio Pie/Donut Chart + Bar Chart

Transaction history

Save data using localStorage

Export portfolio as TXT and CSV

Dark/Light mode

Toast notifications

Fully responsive for mobile and desktop

UI

Make it look like a professional fintech dashboard with modern cards, icons, smooth animations, rounded corners, and clean typography.

Add a small "How It Works" section explaining the formula:

Investment = Stock Price × Quantity

Clearly display:

"Demo prices only — not real-time market prices."

Make everything fully functional with no console errors.
use only python
